# 🌾 AgriFusion

An AI-powered smart agriculture platform that connects farmers and buyers while providing crop recommendations, marketplace services, and an intelligent chatbot to improve agricultural decision-making.

## 🚀 Features

- 👨‍🌾 Farmer Dashboard
- 🛒 Marketplace for Farmers & Buyers
- 🤖 AI Chatbot Assistance
- 👤 User Authentication
- 📊 Admin Dashboard
- 🌱 Crop Recommendation
- 📱 Responsive UI
- ☁️ Supabase Backend Integration


# 🛠 Tech Stack

# Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

# Backend
- Supabase

# Database
- PostgreSQL (Supabase)

# ⚙️ Installation

Clone the repository

git clone https://github.com/ArpitaSingh258/Agrifusion.git

Go to project folder

cd Agrifusion

Install dependencies

npm install


Run the project

npm run dev
